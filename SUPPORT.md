# Support

SUS Digital Labs is an independent open-source initiative. We provide community support through GitHub. We do not provide formal SLAs or institutional support.

## How to get help

* **Bug reports**: Open a public issue using the Bug Report template.
* **Feature requests**: Open a public issue using the Feature Request template, or start a Discussion.
* **Security vulnerabilities**: Do **NOT** open a public issue. Use GitHub Private Vulnerability Reporting on the specific repository.
* **Usage questions**: Use GitHub Discussions (if enabled) or search past issues.
* **Sensitive health data**: NEVER PUBLIC. We do not process real health data.

We appreciate your contributions and patience.
