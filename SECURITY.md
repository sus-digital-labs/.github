# Security Policy

## Reporting vulnerabilities
Please **DO NOT** report security vulnerabilities or sensitive health information through public GitHub issues. 

Use GitHub Private Vulnerability Reporting (Settings → Security → Private vulnerability reporting) if available on the repository, or contact the maintainers directly through secure channels.

## Sensitive health data
Under no circumstances should real patient data, CPF, CNS, clinical data, real municipal database dumps, or private credentials be included in issues, discussions, or pull requests. All test data must be strictly synthetic.

## Supported versions
We currently support the `main` branch and the latest stable release of our active repositories.

## Scope
This policy applies to all repositories under the `sus-digital-labs` organization.
